# Хуманизатор: офлайн-приложение

Статический сайт (PWA), который работает целиком на устройстве: телефон или ПК, без сервера и без Claude.

- `core.js` — метод: профиль (GLTR-ранги, Fast-DetectGPT, ритм «удивления», длины предложений, пунктуация, штампы), варианты предложений (штампы, разбивка, замены слов по подсказкам модели, перефразирование локальной моделью), фильтр смысла по эмбеддингам, фильтр «битого» текста по вероятности, покоординатный поиск сочетания, ближайшего к целевому профилю (ваш образец или «типичный человеческий»).
- Модели: `onnx-community/Qwen2.5-0.5B-Instruct` (WebGPU: q4f16, 483 МБ; процессор: int8, 512 МБ) и `Xenova/paraphrase-multilingual-MiniLM-L12-v2` (int8, 118 МБ). Скачиваются с Hugging Face один раз и хранятся в кэше браузера.
- `vendor/` — transformers.js 4.3.0 и onnxruntime-web (WASM), чтобы не зависеть от CDN.
- `sw.js` кэширует само приложение, поэтому оно открывается без сети.

## Запуск

Любой статический хостинг с https (GitHub Pages, Netlify и т.п.) или локально:

```bash
cd docs && python3 -m http.server 8000   # открыть http://localhost:8000
```

На телефоне: открыть адрес, нажать «Скачать модели», затем «Добавить на главный экран».

Самопроверка без интернета на крошечных тестовых моделях: положить их в `docs/models/test-lm` и `docs/models/test-embed` и открыть `index.html?selftest`.

## Публикация на GitHub Pages

В этом репозитории приложение лежит в `docs/`: Settings → Pages → Deploy from a branch → `main` / `docs`. Все пути относительные, поэтому сайт работает и по адресу вида `https://<user>.github.io/<repo>/`. Файл `.nojekyll` нужен, чтобы Pages отдавал папку `vendor/` как есть.
